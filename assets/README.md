# Project Assets & Images

Upload your screenshots and generated plots (e.g., from the `results/plots/` folder) into this directory.

Recommended files to place here:
1. `dashboard_screenshot.png` - A screenshot of your Streamlit Live Log Tester.
2. `shap_chart.png` - A screenshot of the SHAP feature importance plot.
3. `confusion_matrix.png` - The heatmap generated by the pipeline.

After placing the files here, the main `README.md` will automatically load them!
